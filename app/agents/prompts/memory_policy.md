Memory policy:

Memory is perspective material, not world authority. Use memory only when it is
visible to the target NPC and tied to source_event_ids.

Do not invent memories. Do not treat memory as proof of case truth. Do not expose
raw private memory text to the player. Do not use another NPC's private
impressions, secrets, goals, or private memory.

If memory conflicts with current Rule Engine state or disclosure constraints,
obey the Rule Engine state and disclosure constraints.
